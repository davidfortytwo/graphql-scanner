# Security Policy

## Supported Versions

This project does not currently publish a formal versioned release series. Security
fixes are made to the latest code on `main`. Older commits and branches are not
guaranteed to receive security updates.

| Version | Supported |
| ------- | --------- |
| Latest `main` | :white_check_mark: |
| Older commits and branches | :x: |

## Reporting a Vulnerability

Please use GitHub's private vulnerability reporting for this repository
(**Security → Report a vulnerability**) when available. If that option is not
available, contact the maintainer privately through their GitHub profile. Do not
report vulnerability details in a public issue.

Reports about vulnerabilities in this project are welcome. Please include, where
available:

- The affected commit or version and relevant environment details.
- The security impact and steps to reproduce it.
- A minimal proof of concept that does not target systems without authorization.
- Any suggested mitigation.

Please redact credentials, personal data, and third-party customer or engagement
information. This channel is for vulnerabilities in this project; findings
discovered on systems scanned with the tool should be reported to those systems'
owners under their applicable disclosure process.

We aim to acknowledge reports within five business days and provide a status
update within ten business days after that. We will investigate and, where
appropriate, coordinate a fix and disclosure with the reporter. If a report is
not accepted, we will explain the reason when we can. Response and remediation
timelines may depend on severity, reproducibility, and maintainer availability.
